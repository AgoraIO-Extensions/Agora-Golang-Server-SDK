## 集成流程

### 1. 从 web entry 接口获取房间类型

- `sysConfig` 对象结构如下：

| 字段            | 类型      | 说明                        |
|-----------------|-----------|----------------------------|
| rtcChannelType  | Integer   | RTC频道类型，0普通频道，1大频道，默认为0 |

- 根据 `rtcChannelType` 的值，在 RTC 调用时设置频道类型。赋值到currentChannelType中。
currentChannelType = web.response.sysConfig.rtcChannelType  ### 0416修改

### 2. 设置 RTC 频道类型

- 如果 `currentChannelType == 1`，则设置频道类型为 `agoraservice.ChannelTypeLargeScale`； ### 0416修改
- 否则：
    - `接口没有返回sysConfig`或者，
    - `sysConfig没有rtcChannelType`或者，
    - `rtcChannelType == 0` 
    则设置频道类型设置为 `agoraservice.ChannelTypeStandard`。

**示例代码：**

```go
conCfg := &agoraservice.RtcConnectionConfig{
    AutoSubscribeAudio: false,
    AutoSubscribeVideo: false,
    ClientRole:         agoraservice.ClientRoleBroadcaster,
    ChannelProfile:     agoraservice.ChannelProfileLiveBroadcasting,
}

if currentChannelType == 1 {
    conCfg.ChannelType = agoraservice.ChannelTypeLargeScale
} else {
    conCfg.ChannelType = agoraservice.ChannelTypeStandard
}

con = agoraservice.NewRtcConnection(conCfg, publishConfig)
```

### 3. 接收编码视频流时的改动

- `OnEncodedVideoFrame` 方法签名由

    ```go
    func(uid string, imageBuffer []byte, frameInfo *agoraservice.EncodedVideoFrameInfo)
    ```

  改为：

    ```go
    func(channelId string, uid string, imageBuffer []byte, frameInfo *agoraservice.EncodedVideoFrameInfo)
    ```

- 增加了一个参数 `channelId`，其他没有改变。

### 4. 针对大频道增加私有参数: 0416修改； NOTE：仅仅是针对大频道，标准频道不需要设置！！！

- 如果是large scale频道，则需要在 `con.Connect()` 之前调用如下方法设置：

```go
//only for large scale channel
### 0416 修改
	if currentChannelType == agoraservice.ChannelTypeLargeScale {
		con.GetAgoraParameter().SetParameters("{\"rtc.stream_sub_remote_stats\":false}")
		con.GetAgoraParameter().SetParameters("{\"rtc.stream_pub_local_stats\":false}")
        // 这个参数[vocs_list参数]在0421之后必须移除，否则会订阅失败
		con.GetAgoraParameter().SetParameters("{\"rtc.vocs_list\":[\"81.70.100.39\"]}")
	}
```

- 然后再连接：

```go
info := ""
con.Connect(token, channelName, userId, info)
```

### 5. Connect 方法新增参数 `info`

- 目前设置为空字符串即可。

```go
info := ""
con.Connect(token, channelName, userId, info)
```

# 兆维集成方案1.0

## 1. 私有参数的设置

### 1.1 设置的位置

在 `agoraservice.Initialize()` 之后、建立 connection 前，调用 `agoraservice.GetAgoraParameter().SetParameters()` 来设置私有参数。

### 1.2 示例代码

```go
agoraservice.Initialize(svcCfg)
// global private parameters
parameterHandler := agoraservice.GetAgoraParameter()
parameterHandler.SetParameters("{\"che.video.minQP\":21}")
parameterHandler.SetParameters("{\"rtc.video.low_stream_enable_hw_encoder\":false}")
parameterHandler.SetParameters("{\"engine.video.enable_hw_encoder\":false}")
parameterHandler.SetParameters("{\"rtc.video.enable_minor_stream_intra_request\":true}")
parameterHandler.SetParameters("{\"rtc.video.enable_pvc\":false}")
parameterHandler.SetParameters("{\"rtc.video.color_space_enable\":true}")
parameterHandler.SetParameters("{\"rtc.video.videoFullrange\":1}")
parameterHandler.SetParameters("{\"rtc.video.matrixCoefficients\":5}")
```

---

## 2. publishConfig 参数的修改（更新）

### 2.1 修改点

需要将 `publishConfig.VideoPublishType` 从 `agoraservice.VideoPublishTypeEncodedImage` 修改为 `agoraservice.VideoPublishTypeYuv`。

### 2.2 示例代码

```go
publishConfig := agoraservice.NewRtcConPublishConfig()
publishConfig.AudioPublishType = agoraservice.AudioPublishTypePcm
publishConfig.AudioScenario = scenario
publishConfig.IsPublishAudio = true
publishConfig.IsPublishVideo = true
publishConfig.VideoPublishType = agoraservice.VideoPublishTypeYuv
publishConfig.AudioProfile = agoraservice.AudioProfileDefault
```

---

## 3. 增加 yuv 视频编码参数和大小流编码参数的设置

### 3.1 设置时序

在 `connection.Connect()` 后，调用 `con.SetVideoEncoderConfiguration()` 设置 yuv 视频编码参数，调用 `con.SetSimulcastStream()` 设置大小流编码参数。

### 3.2 示例代码

```go
encoderCfg := agoraservice.NewVideoEncoderConfiguration()
encoderCfg.Width = 1280
encoderCfg.Height = 720
encoderCfg.Framerate = 24

encoderCfg.Bitrate = 1250
encoderCfg.MinBitrate = -1
encoderCfg.DegradePreference = agoraservice.DegradeMaintainFramerate

con.SetVideoEncoderConfiguration(encoderCfg)
con.SetSimulcastStream(true, &agoraservice.SimulcastStreamConfig{
    Width: 384,
    Height: 216,
    Bitrate: 300,
    Framerate: 10,
})
```

---

## 4. 视频编码帧观察者的修改

### 4.1 修改点

设置为接收视频编码帧，但不进行解码。`connectionConfig` 中需设置 `AutoSubscribeVideo: false`。

### 4.2 设置时序

在建立 `connection.Connect()` 后，调用 `con.GetLocalUser().SubscribeVideo(uid, ...)` 或 `SubscribeAllVideo(...)` 来设置只接收编码帧。

### 4.3 示例代码

```go
con.GetLocalUser().SubscribeAllVideo(&agoraservice.VideoSubscriptionOptions{
    StreamType:       agoraservice.VideoStreamHigh,
    EncodedFrameOnly: true,
})

conCfg := &agoraservice.RtcConnectionConfig{
    AutoSubscribeAudio: true,
    AutoSubscribeVideo: false,
    ClientRole:         agoraservice.ClientRoleBroadcaster, // 设置为观众角色，只接收不发送
    ChannelProfile:     agoraservice.ChannelProfileLiveBroadcasting,
}
```

---

## 5. 如何推流

当接收到 SIP 终端传来的视频流后，从原来的 `PushVideoEncodedData` 修改为 `PushVideoEncodedDataForTranscode`。

- **只针对摄像头流，不针对共享流！**
